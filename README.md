# Akash Patel — Portfolio

A responsive, static portfolio website for Akash Patel.

## Preview locally
Open `index.html` in a web browser.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `akashpatel.github.io` (or another repository name).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
3. If you used a repository other than `akashpatel.github.io`, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish. Your site URL will be shown in Settings → Pages. A user-name repository typically uses `https://YOUR-USERNAME.github.io/`.

The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.

## Customize
Edit the text in `index.html` and colors/layout in `styles.css`. The project descriptions are intentionally general; replace them with approved work samples or case studies before publishing.
